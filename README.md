## 📖 Usage

### Basic Usage

```typescript
import { createFilmAnalyst } from './src/agents/main-analyst';

const analyst = createFilmAnalyst('standard');

const review = await analyst.analyzeFilm({
  film: {
    title: 'Example Film',
    year: 2024,
    director: 'Director Name',
    genre: ['Drama', 'Thriller'],
  },
  analysisDepth: 'standard',
  spoilerLevel: 'minimal',
  outputFormat: 'structured-report',
});

console.log(review.data);
```

### Advanced Usage (Comprehensive Analysis)

```typescript
import { createComprehensiveAnalyst } from './src/agents/main-analyst';

const analyst = createComprehensiveAnalyst();

const review = await analyst.analyzeFilm({
  film: {
    title: 'Complex Film',
    year: 2024,
    director: 'Auteur Director',
    genre: ['Drama'],
    runtime: 150,
  },
  analysisDepth: 'comprehensive',
  spoilerLevel: 'full',
  outputFormat: 'structured-report',
});

// Access advanced cognitive analysis
const cognitiveLoad = review.data.analysis.cognitiveLoad;
const emotionalResponse = review.data.analysis.emotionalResponse;
const comprehension = review.data.analysis.comprehension;

console.log(`Cognitive Load: ${cognitiveLoad.overallCognitiveLoad}/10`);
console.log(`Emotional Intensity: ${emotionalResponse.emotionalIntensity}/10`);
console.log(`Comprehension: ${comprehension.overallComprehension}/10`);
```

## 📊 Scoring Methodology

### Research-Backed Weights

Scores use weighted Multi-Criteria Decision Analysis (MCDA) with weights informed by empirical research:

| Dimension | Weight | Research Basis |
|-----------|--------|----------------|
| Narrative | 25% | Stein & Glenn: Causal structure primary comprehension factor |
| Visual | 25% | Cutting/Serafine: Visual provides 50% of film information |
| Performance | 20% | Keen/Eder: Identification strength predicts transportation |
| Audiovisual | 15% | Stein/Spence: Integration affects comprehension |
| Originality | 10% | Nęcka: Schema violation enhances engagement |
| Coherence | 5% | Stein & Glenn: Themes support but don't drive comprehension |

### Confidence Intervals

All scores include 95% confidence intervals calculated using conservative single-case analysis standards (margin of error: ±1.5).
