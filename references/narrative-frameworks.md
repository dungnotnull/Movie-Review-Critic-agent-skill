# Narrative Frameworks — Operational Reference

## Purpose

This file provides operationalized criteria for analyzing film narrative structure using established frameworks. Use the checklists and evaluation standards here to produce consistent, defensible narrative analysis.

## Framework 1: Three-Act Structure (Syd Field, 1979)

### Source

Field, S. (1979). *Screenplay: The Foundations of Screenwriting*. Delta.

### Core Principle

Narrative comprises three structural units: Setup (Act I), Confrontation (Act II), and Resolution (Act III). Proper pacing requires each act to occupy approximately 25%, 50%, and 25% of narrative duration respectively.

### Operational Checklist

**Act I: Setup (0-25%)**
- [ ] Establishes protagonist's status quo ("ordinary world")
- [ ] Introduces protagonist's goal/need
- [ ] Presents inciting incident that disrupts status quo
- [ ] Protagonist accepts call to action (plot point 1)
- [ ] stakes are clearly established

**Act II: Confrontation (25-75%)**
- [ ] Protagonist attempts to achieve goal, faces obstacles
- [ ] Obstacles progressively increase difficulty
- [ ] Midpoint shifts context or raises stakes
- [ ] Protagonist experiences low point/all-is-lost moment
- [ ] Gathers resources/courage for final push
- [ ] Plot point 2 propels toward climax

**Act III: Resolution (75-100%)**
- [ ] Climax confrontation with primary obstacle
- [ ] Protagonist succeeds or fails based on earlier choices
- [ ] Consequences revealed
- [ ] New status quo established
- [ ] Thematic conclusion reached

### Evaluation Standards

**Effectiveness Rating (0-10):**
- 9-10: All criteria met, pacing precise, stakes clear, progression organic
- 7-8: Most criteria met, minor pacing issues, stakes mostly clear
- 5-6: Basic structure present, significant gaps or pacing problems
- 3-4: Structure identifiable but major flaws, unclear stakes
- 0-2: No coherent three-act structure

**Common Issues to Flag:**
- Act II bloat (exceeds 60% of narrative)
- Missing or weak inciting incident
- Unclear or shifting protagonist goal
- Deus ex machina resolution (unearned)
- Missing plot points or weak transitions

## Framework 2: The Hero's Journey (Campbell, 1949; Vogler, 1992)

### Sources

Campbell, J. (1949). *The Hero with a Thousand Faces*. Pantheon.
Vogler, C. (1992). *The Writer's Journey: Mythic Structure for Writers*. Michael Wiese Productions.

### Core Principle

Narrative follows monomyth pattern where hero departs ordinary world, faces trials, gains insight, returns transformed. Not all stages required; presence and sequence varies by story.

### Operational Checklist

**Departure**
- [ ] Ordinary World established
- [ ] Call to Adventure presented
- [ ] Refusal of Call (optional but common)
- [ ] Mentor provides aid/guidance
- [ ] Crossing Threshold into special world

**Initiation**
- [ ] Tests/Allies/Enemies encountered
- [ ] Approach to inmost cave
- [ ] Ordeal (supreme test)
- [ ] Reward (seizing sword)

**Return**
- [ ] Road Back (recommitment to journey)
- [ ] Resurrection (final, more dangerous test)
- [ ] Return with Elixir (benefit to ordinary world)

### Evaluation Standards

**Completeness Rating:** Count stages present (0-12)
- 10-12 stages: Complete monomyth
- 7-9 stages: Strong monomyth presence
- 4-6 stages: Partial monomyth
- 1-3 stages: Minimal monomyth

**Effectiveness Rating (0-10):**
- 9-10: Clear progression through stages, each serves character/thematic development
- 7-8: Strong journey, minor stages missing or weak
- 5-6: Basic journey structure, significant gaps
- 3-4: Some stages present but progression unclear
- 0-2: No coherent Hero's Journey

**Common Issues to Flag:**
- Stages present but lacking narrative purpose
- Missing crossing threshold or ordeal
- No transformation/equivent to return
- Incoherent stage sequence

## Pacing Analysis

### Framework

Bordwell, D. (1985). *Narration in the Fiction Film*. University of Wisconsin Press.

- **Deliberate:** Slow-burn, extended takes, emphasis on atmosphere
- **Balanced:** Mix of节奏, maintains engagement without rushing
- **Brisk:** Fast-moving, quick cuts, information-dense
- **Uneven:** Inconsistent pacing, jarring shifts

**Per-Act Pacing Evaluation:**
1. Does act length serve its narrative purpose?
2. Do information reveals come at appropriate tempo?
3. Does tension build/release effectively?

## Thematic Depth Analysis

### Framework

Thematic coherence across narrative elements: plot, character, dialogue, visual metaphor, sound design.

### Operational Criteria

**Primary Theme Identification:**
1. What is the central question/issue the film explores?
2. How is this theme introduced?
3. How does it develop across acts?
4. How is it resolved/complicated?

**Thematic Development Rating (0-10 per theme):**
- 9-10: Clear introduction, development across acts, nuanced resolution
- 7-8: Clear theme, solid development, somewhat pat resolution
- 5-6: Theme identifiable but development inconsistent
- 3-4: Theme hinted but not fully developed
- 0-2: No coherent theme

**Coherence Assessment (0-10 overall):**
- Do all narrative elements support thematic conclusion?
- Are there thematic contradictions?
- Does visual/audio design support theme?

## Framework Selection Guide

**Use Three-Act Structure when:**
- Film follows linear, goal-oriented narrative
- Clear protagonist with identifiable objective
- Conventional narrative progression

**Use Hero's Journey when:**
- Film features transformational arc
- Mythic or epic scope
- Clear separation between ordinary/special worlds

**Use Non-Linear designation when:**
- Film employs flashbacks, time jumps, or fractured chronology
- Narrative order doesn't follow chronological events
- Structure itself is thematic

---

## Common Structural Patterns Beyond Core Frameworks

**Non-Linear Patterns:**
- Flashback structure
- Rashomon effect (multiple perspectives)
- Reverse chronology
- Circular narrative
- Parallel storylines

When these are present, adapt analysis to address:
1. How does structure serve theme?
2. Is structural complexity earned or gratuitous?
3. Does chronology manipulation clarify or confuse?
