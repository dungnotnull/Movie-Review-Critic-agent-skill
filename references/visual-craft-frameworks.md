# Visual Craft Frameworks — Operational Reference

## Purpose

This file provides operationalized criteria for analyzing film visual craft using established frameworks. Use the checklists and evaluation standards here to produce consistent, defensible visual analysis.

---

## Framework 1: Mise-en-scène Analysis (Bordwell & Thompson)

### Source

Bordwell, D., & Thompson, K. (2013). *Film Art: An Introduction* (10th ed.). McGraw-Hill.

### Core Principle

Mise-en-scène encompasses everything placed before the camera: sets, costumes, lighting, actors, composition. How these elements are arranged creates meaning and guides audience interpretation.

### Operational Checklist

**Setting/Production Design**
- [ ] What historical period, geographic location, or social environment is established?
- [ ] How does setting reflect character states or thematic concerns?
- [ ] Are props/significant objects used symbolically?
- [ ] Does setting change to reflect narrative progression?

**Costume & Makeup**
- [ ] How do costumes reflect character traits, status, or development?
- [ ] Does costume change signal character transformation?
- [ ] Is makeup age/situation appropriate?
- [ ] Do costume choices serve genre conventions or subvert them?

**Lighting**
- [ ] What lighting scheme is used (high-key, low-key, available)?
- [ ] How does lighting create mood or emphasize key elements?
- [ ] Does lighting shift to reflect narrative/thematic beats?
- [ ] Are shadows/light used symbolically?

**Acting/Performance within Frame**
- [ ] How are actors positioned in relation to each other and environment?
- [ ] Does staging/blocking convey power dynamics or relationships?
- [ ] Are significant choices made about who occupies foreground/background?

**Composition/Framing**
- [ ] What's included/excluded from frame and why?
- [ ] How does composition guide viewer attention?
- [ ] Are significant shapes/patterns used for effect?
- [ ] Does shot composition reinforce or contradict scene content?

### Evaluation Standards

**Effectiveness Rating (0-10):**
- 9-10: All mise-en-scène elements work together coherently, every choice serves narrative/thematic purpose, visual storytelling rich
- 7-8: Strong use of elements, minor inconsistencies, generally effective visual communication
- 5-6: Basic competence, some elements work against others, mixed effectiveness
- 3-4: Significant mise-en-scène problems, elements contradict each other, confusing visual storytelling
- 0-2: Mise-en-scène actively undermines narrative or is fundamentally broken

## Framework 2: Cinematography Analysis

### Source

Giannetti, L. (2013). *Understanding Movies* (13th ed.). Pearson.

### Core Principles

Cinematography encompasses camera work (movement, placement, lens choice) and photographic properties (film stock/digital sensor, color, exposure). These choices create meaning beyond content.

### Operational Checklist

**Camera Movement**
- [ ] What movement patterns are used (static, handheld, steadicam, dolly, crane)?
- [ ] Does movement shift to reflect narrative states or character perspective?
- [ ] Is movement motivated by character action, atmosphere, or thematic concern?
- [ ] Are significant camera moves identifiable and justified?

**Shot Types & Angles**
- [ ] What shot sizes dominate (extreme long, long, medium, close-up, extreme close-up)?
- [ ] How do shot size choices serve the scene?
- [ ] What camera angles are used (eye-level, high, low, Dutch)?
- [ ] Do angle shifts convey power dynamics or character states?

**Lens & Depth**
- [ ] What lens choices are apparent (wide, normal, telephoto)?
- [ ] How does depth of field affect focus/attention?
- [ ] Are focus pulls used for emphasis or transition?
- [ ] Does lens choice distort or clarify for effect?

**Color & Photographic Properties**
- [ ] What color palette dominates (warm/cool, saturated/desaturated)?
- [ ] How does color serve narrative/thematic purpose?
- [ ] Are color shifts used to indicate states/locations/transitions?
- [ ] Is contrast/exposure manipulated for effect?

**Aspect Ratio & Format**
- [ ] What aspect ratio is used and why?
- [ ] Does format choice serve the narrative?
- [ ] Are aspect ratio shifts used (pre-release/IMAX/etc.)?

### Evaluation Standards

**Effectiveness Rating (0-10):**
- 9-10: All cinematographic choices serve narrative/thematic purpose, visual language sophisticated and consistent
- 7-8: Strong cinematography, minor inconsistencies or missed opportunities
- 5-6: Competent work, some choices feel generic or unmotivated
- 3-4: Significant cinematographic issues, choices work against narrative
- 0-2: Cinematography actively undermines film or is technically flawed

### Analysis Template

```markdown

- Effectiveness: [X/10]

**Lens & Focus:**
- Lens choices: [apparent lens selections]
- Depth of field use: [how focus guides attention]
- Effectiveness: [X/10]

**Color & Photographic Properties:**
- Color palette: [describe dominant colors and shifts]

- Technical approach: [film vs digital, contrast choices]
- Effectiveness: [X/10]
```

## Framework 3: Visual Storytelling Assessment

### Core Principle

Visual storytelling conveys information, emotion, and theme through images rather than dialogue. Effective visual storytelling shows rather than tells.

### Operational Checklist

- [ ] Does image composition convey information that dialogue doesn't?
- [ ] Are visual metaphors used to express abstract concepts?
- [ ] Do visual motifs recur to create patterns/meaning?
- [ ] Does visual design change to reflect character states or narrative progression?
- [ ] Are significant visual motifs identifiable and traceable?

### Evaluation Standards

**Visual Storytelling Effectiveness (0-10):**
- 9-10: Rich visual metaphor, consistent motifs, information conveyed visually, images do heavy lifting
- 7-8: Strong visual elements, some reliance on dialogue, generally effective
- 5-6: Mixed approach, some visual storytelling but heavy dialogue dependence
- 3-4: Visuals largely decorative, little narrative/thematic work
- 0-2: No meaningful visual storytelling

### Analysis Template

```markdown

**Visual Metaphors:**
[List 2-3 visual metaphors and their meanings]

**Recurring Motifs:**
[List 2-3 recurring visual elements and their significance]

**Information Conveyed Visually:**
[Describe key moments where image rather than dialogue conveys information]

**Effectiveness:** [X/10]
[Assessment of visual storytelling strength]
```

## Notable Shots Analysis

When a shot stands out, analyze:

1. **Composition:** What's in the frame and why?
2. **Movement:** Any camera movement and its purpose?
3. **Lighting/Color:** How do these serve the shot?
4. **Duration:** How long and why?
5. **Narrative Function:** What information, emotion, or theme does it convey?

### Template

```markdown
**Notable Shot [X]:**
- Timestamp: [if known/applicable]
- Description: [visual description]
- Composition: [analysis of arrangement]
- Technical elements: [lighting, color, movement]
- Narrative purpose: [what it accomplishes]
- Effectiveness: [X/10]
```

## Visual Craft Integration Assessment

Evaluate how visual elements work together:

- [ ] Do cinematography and mise-en-scène complement each other?
- [ ] Is there visual consistency across the film?
- [ ] Do visual shifts (if any) serve narrative purpose?
- [ ] Does visual approach match genre expectations (or intentionally subvert)?

### Template

```markdown
**Visual Craft Integration:**
- Consistency: [assessment of visual coherence]
- Complementary elements: [how cinematography/mise-en-scène work together]
- Genre alignment: [relation to genre visual conventions]
- Overall visual effectiveness: [X/10]
```

## Technical Notes Category

When relevant, note:

- **Capture format:** Film stock (35mm, 16mm, etc.) or digital (specific camera/sensor)
- **Aspect ratio:** Standard (1.85:1, 2.39:1, etc.) or unusual
- **Color grading:** Specific grading approach if identifiable
- **Special processes:** Black & white, colorization, CGI integration, etc.
- **Format rationale:** Why these technical choices were made
